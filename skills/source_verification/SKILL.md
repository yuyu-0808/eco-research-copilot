# 信源可靠性评级规范（行研专属）

## 定位

本规范用于判断每一条信源该信几分。

它把「**这个来源本身可不可信**」和「**这条具体信息可不可信**」分开评。
因为一个权威媒体也可能在某一件事上出错，一个普通来源也可能恰好拿到一手数据。

## 维度一：来源可靠性（Source Reliability）A-F 六级

| 等级 | 含义 | 判定标准 | 采信策略 |
|------|------|---------|---------|
| **A** | 一手官方 | 政府 / 国际组织 / 官方统计 / 公司官方公告 | 最高可信，政策类结论的必需来源 |
| **B** | 权威媒体 | 有严格编辑审核的主流媒体（新华社/路透/财新等） | 采信，核心数据的优质来源 |
| **C** | 行业专业 | 行业协会 / 专业研究机构 / 垂直行业媒体（中汽协/乘联会/IEA/集微/券商研报） | 采信，行业数据与竞争格局的优质来源 |
| **D** | 一般来源 | 其他正常网站，无明确权威背书 | 谨慎对待，需交叉印证 |
| **E** | 低质来源 | 营销号 / 内容农场 / 震惊体标题 | 直接丢弃 |
| **F** | 无法判断 | 匿名 / 无法追溯发布者 / 无 URL | 不采信 |

> 「行业专业机构」单独设为 **C 级**——行业协会、专业研究机构、券商研报是行研场景里最有价值的信源类型，
> 既非官方也非普通媒体，故单列一级。

## 维度二：信息可信度（Information Credibility）

由**代码校验器**承载，不另设 1-6 档：

- **证据数量**：每个必答章节是否凑够最少有效证据数
- **信源等级门槛**：核心指标是否有足够高等级（A/B/C）信源支撑
- **数值归一化**：不同写法（30% vs 0.3）归一化后比对，只对真矛盾标红
- **口径契约**：比例型指标（渗透率/增速/份额）越界（如 150%）被硬拦截

**核心思想**：来源评级回答"信不信这个来源"，代码校验回答"信不信这条数据"——
两者正交，共同构成防幻觉的完整闭环。

## 使用规则

1. **采集即评级**：信源研究员在采集阶段就给每条信源打 A-F 等级，不得留空。
2. **分级采信**：事实稽核官按等级采信——A/B/C 采信、D 谨慎、E/F 丢弃。
3. **不默认信任高等级**：A 级来源也可能在具体事件上出错，仍需交叉印证。
4. **无法判断即 F**：匿名、无 URL、无法追溯发布者的来源一律 F，不采信。
