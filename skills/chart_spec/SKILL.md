# 行研图表规范（Chart Spec）

本规范用于行业研究报告的图表生成。核心原则：**图表类型由数据语义决定，不随意发挥**。

## 一、图表选择规则（按行研数据场景）

| 数据场景 | 推荐图表类型 | 说明 |
|---------|------------|------|
| 时间序列趋势（营收/渗透率/出货量逐年演变） | line 折线图 | 强调趋势走向 |
| 龙头 vs 其他厂商份额对比 | bar 柱状图 | 横向条形更利于读名次 |
| 占比结构（≤5 项，如能源结构/收入构成） | pie 饼图 | 强调比例关系 |
| 占比结构（>5 项） | bar 柱状图 | 类别多时饼图难读，改柱状 |
| 多公司/多赛道增速横向对比 | bar 柱状图 | 按数值降序排列 |
| 政策时间线 / 里程碑梳理 | bar 柱状图 | 横向时间轴表达 |
| 双指标关系（如销量 vs 价格） | bar 柱状图 | 柱线组合，当前简化为柱状 |
| 产业链价值分布（上游→中游→下游） | bar 柱状图 | 瀑布图简化，强调递变 |

> 说明：当前交付层支持 line / bar / pie / area 四类，瀑布图、堆叠柱、组合图暂以 bar 或 line 近似表达。

## 二、风格规范（统一观感）

1. **完整图题**：标题须为完整图题，含编号与描述，如「图1：2020—2024 中国新能源汽车销量趋势」。
2. **单位标注**：legend label 必须带单位，如「销量(万辆)」「市场份额(%)」。
3. **数据来源**：图表下方需标注数据来源（信源标题），保证可溯源。
4. **配色**：单主题色，重点数据用深色高亮，其余用浅色，避免花哨渐变。
5. **排序**：横向对比类图表（厂商份额、增速排行）按数值降序排列，直观呈现名次。

## 三、输出约束

- 图表数据必须来自「已核验的数据与信源」，严禁编造数值。
- 每个图表只表达一个核心结论，不堆砌多维度。
- 图表数量 2—4 张为宜，与正文分析一一对应。
